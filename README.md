# 🐾 DAIMS

## Dead & Injured Animal Management System

DAIMS (Dead & Injured Animal Management System) is a web-based platform designed to help citizens report dead or injured animals quickly and efficiently.

The system connects citizens with registered administrators or organizations responsible for animal welfare, enabling faster response and better management of animal-related complaints.

---

## 🌟 Features

### 👤 Citizen Features

* Report dead or injured animals
* Select animal condition (Dead / Injured)
* Upload animal photo
* Share current GPS location
* Enter area, district, city, or village
* Submit complaints online
* Multilingual interface support

### 🛡️ Admin Features

* Admin registration and login
* Area-based complaint management
* View reported animal details
* View uploaded animal images
* Open complaint location in Google Maps
* Navigate directly to the reported location
* Update complaint status

  * Pending
  * In Process
  * Completed
* Delete complaints
* Dashboard with complaint statistics
* Complaint reports and summary

---

## 📊 Admin Dashboard

The admin dashboard provides an overview of all complaints.

* Total Complaints
* Pending Complaints
* In Process Complaints
* Completed Complaints

Admins can efficiently manage and track animal complaints from a centralized dashboard.

---

## 🔄 Complaint Workflow

1. Citizen finds a dead or injured animal.
2. Citizen opens the DAIMS website.
3. Citizen fills in complaint details.
4. Citizen selects the animal condition.
5. Citizen uploads a photo.
6. Citizen shares their current location.
7. Complaint is submitted.
8. Admin receives and views the complaint.
9. Admin updates the complaint status.
10. Complaint is marked as completed after action is taken.

## 🎯 Objective

The main objective of DAIMS is to provide a simple digital platform for reporting and managing cases involving dead and injured animals.

The system aims to:

* Improve response time
* Simplify complaint reporting
* Provide accurate location information
* Help animal welfare organizations
* Improve coordination between citizens and authorities
